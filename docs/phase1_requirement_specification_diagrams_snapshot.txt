flowchart TD
    Start(("Start")) --> Login["User Logs In via Supabase Auth (ES256 JWT)"]
    Login --> Browse["Browse Movies, Cinemas & Showtimes"]
    Browse --> ViewSeats["View Real-Time Seat Map<br/>(Expired Holds Shown as AVAILABLE)"]
    ViewSeats --> SelectSeats["Select Seats (1 to 6 Seats)"]
    SelectSeats --> SubmitOrder["Submit Order with Idempotency-Key"]
    SubmitOrder --> CheckLock{"Atomic DB Lock Succeeded?<br/>(AVAILABLE or Expired HELD)"}

    CheckLock -->|"No (Conflict 409)"| ShowConflict["Display Seat Unavailable Error"]
    ShowConflict --> ViewSeats

    CheckLock -->|"Yes"| HoldCreated["Seats Marked HELD (5-min Timer)<br/>Order Created (PENDING_PAYMENT)"]
    HoldCreated --> PayAction{"User Completes Payment<br/>Before 5-min Expiry?"}

    PayAction -->|"No (Timeout)"| ExpireOrder["Order Marked EXPIRED &<br/>Seats Released (Lazy / UptimeRobot)"]
    ExpireOrder --> EndFail((("End")))

    PayAction -->|"Yes"| MockPay["Invoke Mock Payment Adapter"]
    MockPay --> PayResult{"Payment Status?"}

    PayResult -->|"FAILED / TIMEOUT"| RetryCheck{"Within 5-min Hold Window?"}
    RetryCheck -->|"Yes"| PayAction
    RetryCheck -->|"No"| ExpireOrder

    PayResult -->|"SUCCEEDED"| ConfirmTx["Atomic TX: Order -> CONFIRMED<br/>Seats -> SOLD, Generate QR E-Tickets"]
    ConfirmTx --> ViewTicket["Customer Views E-Ticket & QR Code"]
    ViewTicket --> RefundChoice{"Customer Requests Refund?"}

    RefundChoice -->|"No"| Attend["Attend Showtime (Ticket Scanned -> USED)"]
    Attend --> EndOk((("End")))

    RefundChoice -->|"Yes"| CheckCutoff{"Showtime Start >= 60 Mins Away?"}
    CheckCutoff -->|"No"| RejectRefund["Reject Refund (Past 60-min Cutoff)"]
    RejectRefund --> ViewTicket

    CheckCutoff -->|"Yes"| ProcessRefund["Atomic TX: Record Refund, Order -> REFUNDED,<br/>Tickets -> REFUNDED, Seats -> AVAILABLE, Write Audit Log"]
    ProcessRefund --> EndRefund((("End")))

=== FILE: Requirement_Specification/Unified_Modeling_Language/UML_Sequence_Diagram/UML_Sequence_Diagram.mermaid ===
sequenceDiagram
    actor Customer as Customer (Flutter App)
    participant Auth as Supabase Auth
    participant API as FastAPI Backend (Render)
    participant DB as Supabase PostgreSQL
    participant Pay as Mock Payment Adapter
    participant Cron as UptimeRobot (5-min Ping)

    Customer->>Auth: Login / Sign Up
    Auth-->>Customer: Return ES256 JWT
    Customer->>API: GET /api/v1/auth/me (Bearer JWT)
    API->>Auth: Fetch & Cache JWKS (ES256)
    API->>DB: Lazy Upsert public.users & Default CUSTOMER Role
    API-->>Customer: User Profile & Roles

    Customer->>API: GET /api/v1/showtimes/{id}/seats
    API->>DB: Query showtime_seats (Project Expired HELD as AVAILABLE)
    API-->>Customer: Real-Time Seat Map

    Customer->>API: POST /api/v1/orders (Idempotency-Key, seat_ids <= 6)
    API->>DB: BEGIN TX & Atomic UPDATE (AVAILABLE or Expired HELD -> HELD, +5 min)
    alt Seat Conflict / Already Held
        DB-->>API: Updated Rows < Requested Seats (ROLLBACK)
        API-->>Customer: 409 Conflict (Seat Unavailable)
    else Seats Locked Successfully
        API->>DB: INSERT orders (PENDING_PAYMENT) & order_items (COMMIT)
        API-->>Customer: 201 Created (Order + 5-min Countdown)
    end

    Customer->>API: POST /api/v1/orders/{id}/pay (Idempotency-Key, scenario)
    API->>DB: Verify Order PENDING_PAYMENT & hold_expires_at > NOW()
    API->>Pay: Execute Mock Payment (SUCCEEDED / FAILED / TIMEOUT)
    alt Payment SUCCEEDED
        Pay-->>API: Payment Confirmed (provider_tx_id)
        API->>DB: UPDATE orders -> CONFIRMED, seats -> SOLD, INSERT tickets (QR)
        API-->>Customer: 200 OK (Confirmed Order + E-Tickets)
    else Payment FAILED / TIMEOUT
        Pay-->>API: Payment Failed / Unknown
        API->>DB: INSERT payments (FAILED / UNKNOWN)
        API-->>Customer: 402 / 504 Payment Retryable Until Hold Expires
    end

    Cron->>API: GET /internal/jobs/cleanup-holds?token=CRON_SECRET
    API->>DB: Batch Expire Unpaid Orders -> EXPIRED & Release Stale HELD Seats
    API-->>Cron: 200 OK (Keep-Alive & Cleanup Summary)
