0. TEST ENVIRONMENT & BASELINE THRESHOLDS
--------------------------------------------------------------------------------
- Application Tier     : FastAPI on Render.com (Local: pytest + httpx.AsyncClient)
- Data Tier            : Supabase PostgreSQL 15+ (3NF, 15 Tables)
- Auth Provider        : Supabase Auth (ECC P-256 / ES256 JWKS)
- Payment Adapter      : Mock Payment Adapter (SUCCEEDED / FAILED / TIMEOUT)
- Seat Hold Timeout    : SEAT_HOLD_SECONDS=300 (5 mins; overridable to 5s in test)
- Refund Cutoff        : REFUND_CUTOFF_MINUTES=60 (>= 60 mins prior to showtime)
- Max Seats Per Order  : 6 seats
- Test Pyramid Target  : 70% Unit (Service/Domain) | 20% Integration (DB/API) | 10% E2E
